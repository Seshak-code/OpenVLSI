# Generated Code Architecture

The `compute/generated` directory contains the **Automated Artifacts** of the build system.

## Logic: Build-Time Invariance
This includes Protobuf/gRPC stubs, shader binaries (SPIR-V), and any code generated by the `physics_compiler`.
