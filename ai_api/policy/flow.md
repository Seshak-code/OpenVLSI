# AI Policy Flow

The `ai_api/policy/` directory defines the **Grounding Guardrails** of AcuteSim. It enforces the "Evidence-First" philosophy, ensuring that the AI Assistant acts as a scientific analyst rather than a creative writer.

## Key Files & Responsibilities

### 1. AI Policy Definition (`ai_policy.h`)
**Role**: The "Constitutional Guardrail". Defines the strict rules that every AI response must adhere to.
-   **Raw Evidence First**: Forces the system to display raw solver logs (Residuals, Convergence status) *before* any AI-generated text.
-   **Citation Requirement**: Mandates that the AI must cite specific log lines or data points (e.g., "[Line 42]", "Residual: 1e-12") to prove it "read" the results.

```cpp
// ai_api/policy/ai_policy.h
struct AIPolicy {
    // Policy flags
    bool rawEvidenceFirst = true;      // AI explains *after* solver proof shown
    bool requireCitations = true;      // AI must cite log lines or data
    int minCitationsPerResponse = 1;   // Minimum citations required
    
    QStringList requiredEvidenceFields = {
        "convergence_status", "max_residual", "solver_method"
    };
};
```

### 2. Citation Validator (`ai_policy.h`)
**Role**: The "Fact-Checker". A regex-based system that validates AI output before it reaches the user.
-   **Pattern Matching**: Scans for specific citation formats. The AI is prompted to use these formats, and this validator verifies compliance.
-   **Rejection Logic**: If an AI response lacks sufficient citations, it is rejected (or flagged) as "Ungrounded".

```cpp
// ai_api/policy/ai_policy.h
/**
 * Validates an AI response against the policy.
 * Looks for citation patterns like: [Line 42], (Log: "..."), or data values.
 */
static ValidationResult validate(const QString& aiResponse, const AIPolicy& policy) {
    // Pattern 1: [Line N] or [L:N]
    QRegularExpression linePattern(R"(\[(?:Line|L)[:\s]*(\d+)\])");
    
    // Pattern 2: Quoted log text
    QRegularExpression logPattern(R"raw(\(Log:\s*"([^"]+)"\))raw");
    
    // Pattern 3: Data citation (e.g., "Residual: 1.23e-12 A")
    QRegularExpression dataPattern(R"((Residual|Iterations|Convergence):\s*[\d.eE+-]+)");
    
    // ... validation logic ...
}
```

### 3. Evidence Wrapping (`ai_policy.h`)
**Role**: The "Presentation Layer". Mechanically prepends the ground truth to the user interface.
-   **Separation of Concerns**: The AI generates the *explanation*, but the C++ layer generates the *proof*. This prevents the AI from hallucinating a "Successful Simulation" when the engine actually diverged.

```cpp
// ai_api/policy/ai_policy.h
/**
 * Wraps an AI response with evidence header.
 * Ensures solver proof is shown BEFORE AI explanation.
 */
static QString wrapWithEvidence(const QString& aiResponse, 
                                const QJsonObject& solverEvidence,
                                const AIPolicy& policy) {
    if (!policy.rawEvidenceFirst) return aiResponse;
    
    QString evidenceBlock = "## Solver Evidence\n";
    evidenceBlock += QString("- **Status**: %1\n").arg(...);
    evidenceBlock += QString("- **Max Residual**: %1 A\n").arg(...);
    
    evidenceBlock += "\n---\n\n## AI Analysis\n";
    evidenceBlock += aiResponse;
    
    return evidenceBlock;
}
```

## Data Flow
1.  **Solver Execution**: The `compute/` engine runs and producing a `SolverResult` and `SimulationTrace`.
2.  **Prompting**: The `ContextEngine` sends the trace to the AI.
3.  **Generation**: The AI generates a response (e.g., "The floating node at Q1 caused the crash [Line 45]").
4.  **Validation**: `CitationValidator` checks if "[Line 45]" exists and corresponds to a real error log.
5.  **Wrapping**: `wrapWithEvidence` prepends the actual residual table to the message.
6.  **Display**: The user sees the Evidence Block followed by the AI Analysis.

## Development Rules
1.  **No Hallucinations**: The "Solver Evidence" block is generated by deterministic C++ code, NEVER by the LLM.
2.  **Strict Regex**: The regex patterns in `CitationValidator` are the "Law". If the AI uses a new citation format, the C++ code must be updated to recognize it, or the AI must be re-prompted.
3.  **Fail-Safe**: If `minCitationsPerResponse` is not met, the UI should display a warning "AI response may be ungrounded" or retry the generation.
