# OpenVLSI API

Generated by `OpenVLSI --dump-api docs/api.md` from the commands themselves; `tests/test_api` fails when a command is missing here.

Everything in the app is a command, and every menu item and button names the command that does the same (`ui_actions`). Three ways in, one protocol:

- **MCP:** `openvlsi-mcp --workspace <file>` on stdin and stdout. It attaches to a running app on that workspace, so the window follows; otherwise it works on the database (`--headless` asks for that). Commands marked *app* need the running app.
- **Python:** `tools/openvlsi.py`: `openvlsi.connect(workspace).flow_run(design=...)`.
- **The command window:** `command {json arguments}`, or `OpenVLSI --run LINE`.

`api_list` returns all of this at run time, with each command's JSON schema; `api_info` says which mode you reached.

## The API itself

### `api_info`

What this API is: mode app (the running window, which follows every call) or headless (the database only), and how many commands it has.

### `api_list`

Every command: its name, description, parameters as a JSON schema, whether it only reads. query narrows it to names and descriptions holding that text.

| Parameter | Type | Required | Meaning |
|---|---|---|---|
| `query` | string |  | text to look for |

## The window (*app*)

### `ui_actions`

Every menu item and button of the active tab, with the command that does the same.

| Parameter | Type | Required | Meaning |

| Parameter | Type | Required | Meaning |
|---|---|---|---|
| `path` | string | yes | the PNG file to write |

### `ui_input`

Delivers input through the window system's queue, as the platform does, at global points (ui_locate): action move, press, release, click, double_click, drag (to x2, y2), wheel (delta) or key (key as in a shortcut, \"Ctrl+K\" or \"Esc\"; text types). It returns at once: poll ui_input_pending.

| Parameter | Type | Required | Meaning |
|---|---|---|---|
| `action` | string | yes | what to do |
| `button` | string |  | left (default), right or middle |
| `delta` | number |  | a wheel's angle: 120 is one notch away from you |
| `key` | string |  | a key, as in a shortcut |
| `modifiers` | array |  | shift, ctrl, alt, meta |
| `text` | string |  | what to type |
| `x` | number |  | global x |
| `x2` | number |  | a drag's end |
| `y` | number |  | global y |
| `y2` | number |  | a drag's end |

### `ui_input_dropped`

How many inputs found no window to go to since the app started.

### `ui_input_pending`

How much input has not been delivered yet: 0 when everything sent has been handled.

### `ui_library_manager`

| Parameter | Type | Required | Meaning |
|---|---|---|---|
| `kind` | string | yes | what to find |
| `text` | string |  | its text |
| `x` | number |  | x, database units |
| `y` | number |  | y, database units |
